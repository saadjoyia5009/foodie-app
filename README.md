🍔 Foodie App – Flutter Food Delivery Application
Foodie App is a simple and modern food delivery mobile application built using Flutter and Firebase. It provides user authentication, food browsing, cart management, and order placement features. The app uses Firebase Authentication for secure login/signup and Cloud Firestore for storing user and order data. It also includes real-time cart updates with Provider state management.
This project is created for learning and academic purposes, focusing on integrating Flutter with Firebase and building a complete user flow from login to food ordering.
